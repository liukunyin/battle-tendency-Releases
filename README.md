# battle-tendency-Releases

[Play the Web preview](https://liukunyin.github.io/battle-tendency-Releases/)

[Download Windows / Android releases](https://github.com/liukunyin/battle-tendency-Releases/releases)

Web previews use Godot 4.6.3 single-thread exports. The first load downloads approximately 320 MiB. Some symbol icons may render as squares; mobile performance is still being evaluated.

To publish or roll back a Web preview, upload `battle-tendency-web.zip` to a Release, then run **Actions → Deploy Web to GitHub Pages** with that Release tag. The ZIP must contain `index.html`, `index.pck`, and `index.wasm` at its root.
